![Adaptive Performance Tweaks: Bundle][header]

Meta package for CurseForge/Modrinth clients that installs all APTweaks modules automatically (Core,
Game Rules, Items, Player, Spawn).
Works on the server; clients are optional.

⚠️ Important: This bundle JAR does not include the modules themselves.
It is only a meta file for the CurseForge/Modrinth client to resolve and install the modules.
Do not use this JAR for standalone/manual installs.
For manual setups, install the individual modules listed below.

## Status ✅

Stable LTS (Long‑Term Support, Classic Forge).
Actively maintained and recommended for new Forge modpacks.
After 3+ years of development, this Classic line is highly optimized and battle‑tested.
Critical fixes and compatibility updates will be provided when needed. 🛠️

If your pack runs fine on Classic Forge, no action is required. 👍

## 📦 Bundled Modules

This is the bundled version of Adaptive Performance Tweaks which includes all modules together,
like:

- ➡️[Core Module][core] (required by all other modules)
- ➡️[Game Rules Module][gamerules]
- ➡️[Items Module][items]
- ➡️[Player Module][player]
- ➡️[Spawn Module][spawn]

If you want to install only specific modules, please use the module links above instead of this
bundled version.
